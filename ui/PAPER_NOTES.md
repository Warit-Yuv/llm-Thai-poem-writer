# KlonLab: แนวทางใช้ระบบต้นแบบในงานวิจัย

## Research claim ที่ระบบรองรับในปัจจุบัน

ระบบเป็น explainable rule-based validator สำหรับโครงสร้างกลอนสี่และกลอนแปด โดยรวม
พจนานุกรมคำอ่านที่ตรวจแล้ว โมเดลแปลงตัวสะกดเป็นเสียง และ KhaveeVerifier
สำหรับการตรวจสระกับมาตราตัวสะกด ผลลัพธ์ทุกจุดสัมผัสระบุเสียงต้นทาง เป้าหมาย
ตำแหน่งที่พบ และผลผ่าน/ไม่ผ่าน

ระบบยังไม่รองรับ claim ว่าสามารถประเมินความไพเราะ ความหมาย หรือคุณภาพวรรณศิลป์
และยังไม่ควร claim ความแม่นยำจนกว่าจะประเมินกับ gold test set ที่แยกออกมา

## คำถามวิจัยที่เสนอ

1. การเพิ่ม curated pronunciation overrides ลดความผิดพลาดของการนับพยางค์
   เมื่อเทียบกับ w2p เพียงอย่างเดียวได้มากน้อยเพียงใด
2. KhaveeVerifier ตรวจคู่สัมผัสในกลอนสี่และกลอนแปดได้แม่นยำเพียงใดเมื่อเทียบกับ
   annotation จากผู้เชี่ยวชาญ
3. ข้อผิดพลาดกระจุกตัวอยู่ในคำประเภทใด เช่น คำบาลี–สันสกฤต ชื่อเฉพาะ
   หรือคำภาษาโบราณ

## Experimental design

- สุ่มวรรคและคู่สัมผัสจากตอนที่ไม่ถูกใช้แก้ `POETRY_OVERRIDES`
- ใช้ผู้ประเมินอย่างน้อย 2 คนและกำหนด annotation guideline ก่อนเริ่ม
- เก็บ ground truth แยกสำหรับพยางค์และสัมผัส
- รายงาน accuracy/MAE สำหรับจำนวนพยางค์ และ precision, recall, F1 สำหรับสัมผัส
- รายงาน inter-annotator agreement เช่น Cohen's kappa
- เปรียบเทียบ ablation อย่างน้อยสองระบบ:
  1. w2p baseline
  2. `POETRY_OVERRIDES` + w2p + KhaveeVerifier

## Data to retain per run

- เวอร์ชันโค้ดและวันเวลาที่ทดลอง
- ข้อความต้นฉบับ
- พยางค์ที่ระบบแยกได้และแหล่งคำอ่าน
- คู่สัมผัสและตำแหน่งเป้าหมาย
- ผลระบบ ผลผู้เชี่ยวชาญ และหมายเหตุการตัดสิน
- รายการคำที่ fallback ไปยัง w2p

## Threats to validity

- Data leakage หาก gold test set มีคำเดียวกับที่มนุษย์แก้ใน override dictionary
- Corpus bias จากการใช้พระอภัยมณีเป็นแหล่งข้อมูลหลัก
- ความไม่แน่นอนของสัมผัสอนุโลมและการอ่านแบบวรรณคดี
- ความผิดพลาดต่อเนื่องจาก word tokenization ไปยัง syllable และ rhyme checking
- คะแนนโครงสร้างของ UI ไม่ใช่คะแนนคุณภาพบทกลอน

## Demo script สำหรับการนำเสนอ 4 นาที

1. อธิบาย pipeline ข้อความ → คำอ่าน → พยางค์ → สัมผัส
2. วิเคราะห์ตัวอย่างหนึ่งบทและชี้ให้เห็นจำนวนพยางค์ของแต่ละวรรค
3. แสดงเส้นสัมผัสหนึ่งคู่และเปิดรายละเอียดสระ/มาตราตัวสะกด
4. แก้คำท้ายหนึ่งวรรคให้ผิด แล้ววิเคราะห์ใหม่เพื่อแสดง error localization
5. ดาวน์โหลด JSON เพื่อแสดงว่าผลลัพธ์นำไปเก็บเป็น experimental record ได้
6. จบด้วยข้อจำกัดและแผนประเมินกับผู้เชี่ยวชาญ
