# Decorative font

Place a licensed copy of `SOV_sannoga2467` in this directory using a filename that starts with:

`SOV_sannoga2467`

Supported formats are `.ttf`, `.otf`, `.woff`, and `.woff2`. The Streamlit UI embeds the file locally at runtime, so it does not contact a font CDN or cloud service.

The font is used only for the Thai title `ผังกลอน`. The English project name uses Georgia, and interface text keeps a highly readable Thai system font.
